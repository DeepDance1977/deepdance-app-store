# DeepDance App Store

Eigener Community-App-Store für Umbrel und 5tratumOS mit Apps von DeepDance:

- **`deepdance-dashboard`** – BSV Solo Mining Dashboard
- **`deepdance-bitcoin-sv`** – Bitcoin SV Full Node (arm64, Pruned Mode)
- **`deepdance-deepbsv`** – DeepBSV Solo Mining Engine (Stratum V1)

## Einrichtung (5tratumOS / Umbrel)

In den Einstellungen unter "App Store" → "Community App Store hinzufügen":
`https://github.com/DeepDance1977/deepdance-app-store`
